# 🧪 Projeto de Testes: [Urban routes/Urban Scooter]

## 📝 Descrição do Projeto
Este projeto consiste na estratégia e execução de testes para a aplicação **[Urban routes]**, uma plataforma de reserva e pedido de taxi. O objetivo foi garantir a estabilidade das funcionalidades críticas e documentar o processo de QA.

## 🎯 Abordagem de Testes
1. **Análise de Requisitos:** Identificação de cenários críticos.
2. **Criação de Casos de Teste:** Elaboração de passos detalhados e resultados esperados.
3. **Execução:** Testes manuais em ambiente [Web/Mobile].
4. **Reporte de Bugs:** Documentação de falhas encontradas.

## 🛠️ Ferramentas Utilizadas
- **Postman:** Para validação de contratos e respostas de API.
- **Jira:** Para abertura de tickets de bugs.
- **Google Sheets:** Para a matriz de rastreabilidade e casos de teste.
